# Conjugate Heat Transfer (CHT) & CFD Modeling in MATLAB

A MATLAB-based computational fluid dynamics (CFD) package for simulating turbulent, incompressible fluid flow and transient conjugate heat transfer (CHT) in a 2D planar channel.

The project models the coupled fluid dynamics and thermal physics of air flowing over heated solid obstacles. The hydrodynamics are solved to a steady-state using the SIMPLEC pressure-velocity coupling algorithm, while the energy equation is solved transiently to capture the thermal evolution of the system.

## Project Overview
The project was developed in four sequential phases:

### Phase 1: Non-Uniform Mesh Generation & Domain Identification
* Generates a 2D stretched Cartesian mesh, refining the grid in the vicinity of the solid obstacles to capture high-gradient regions accurately.
* Uses `mesh_generator.m` to define the channel geometry and assigns specific domain IDs (fluid vs. solid) to each cell, enabling localized physics.

### Phase 2: Hydrodynamic Flow Solver (SIMPLEC)
* Implements a steady-state, incompressible flow solver based on the SIMPLEC algorithm.
* Solves for the U, V, and P fields iteratively via `solve_momentum.m` and `solve_pressure_correction.m` until a converged flow field is achieved.

### Phase 3: Turbulence Closure (Mixing-Length Model)
* Models turbulence using the algebraic mixing-length model, offering a computationally efficient method for estimating turbulent viscosity.
* Incorporates wall damping effects via the Van Driest function inside `calc_eddy_viscosity.m`.

### Phase 4: Transient Conjugate Heat Transfer (CHT) Solver
* Models the transient heat transfer between the fluid and solid domains using `solve_energy.m`.
* Implements a Finite Volume Method (FVM) solver with an implicit time-stepping scheme and harmonic mean thermal conductivity interpolation at fluid-solid interfaces.

## Solver & Modeling Notes
* **Pressure-Velocity Coupling:** The SIMPLEC algorithm is utilized for its improved convergence characteristics over the standard SIMPLE method.
* **Discretization:** A hybrid upwind/central differencing scheme is applied for convective terms to balance numerical stability and accuracy.
* **Interface Conductivity:** Robust harmonic mean averaging is used directly at fluid-solid boundaries to ensure physically accurate energy balances across vastly different material properties (e.g., $k_s$ vs. $k_f$).

## Theoretical & ANSYS Validation
To ensure the accuracy of the custom FVM solver, the physics logic was theoretically mapped and strictly validated against commercial CFD software (**ANSYS Fluent**). 

The validation confirms two critical theoretical components:
1. **Hydrodynamic Consistency:** The custom SIMPLEC algorithm successfully resolves the Navier-Stokes equations, matching the steady-state velocity profiles, wake generation, and pressure mapping of the Fluent solver.
2. **Thermal Coupling:** The transient energy solver accurately tracks the heat transfer across the fluid-solid boundary. The harmonic mean interpolation logic is proven effective by matching the Fluent transient heating curve of the catalyst blocks.

**Validation Folder:** 
A dedicated `Validation/` directory is included in this repository. It contains direct side-by-side visual comparisons of the results generated by this MATLAB code (Velocity Contours, Temperature Contours, Convergence Residuals, and Max Catalyst Temperature graphs) against the exact same metrics extracted from ANSYS Fluent.

## Requirements and Installation

### Prerequisites
- MATLAB R2020a or higher

### Setup

1. Clone the repository:
```bash
git clone https://github.com/Alireza-Kianifard/conjugate-heat-transfer-cfd.git
cd conjugate-heat-transfer-cfd
```
2. Open MATLAB and navigate to the cloned repository directory.

3. Run the simulation from the MATLAB command window:
```bash
matlab
run main.m
```
